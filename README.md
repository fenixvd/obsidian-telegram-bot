# Obsidian Telegram bot

Заметки в хранилище Obsidian **прямо из Telegram**. Бот живёт в докере рядом с
хранилищем и пишет в него файлами напрямую, поэтому ему не нужен запущенный
Obsidian — в отличие от плагинов, которые работают только при открытом
приложении. Телефон в кармане, Obsidian закрыт, заметка уже в хранилище.

```
переслал пост      →  заметка во входящем лотке по твоему шаблону
прислал ссылку     →  читаемый текст страницы отдельной заметкой
прислал текст      →  строка в ежедневник
/service Immich    →  новая заметка по шаблону из хранилища
/find /read /todo  →  поиск, чтение и открытые задачи, не вставая с дивана
```

Никаких внешних сервисов: только Telegram Bot API и файлы на диске.

## Что внутри

```
.
├── bot.py                  единственный файл с логикой, без зависимостей от конкретного хранилища
├── config.example.yml      папки, шаблоны, команды, тексты ответов
├── templates/              примеры шаблонов — скопировать в хранилище
├── docker-compose.yml
├── Dockerfile
├── requirements.txt
├── .env.example            токен и список своих chat_id
└── selftest.py             офлайн-проверки без Telegram
```

## Как это работает

| Прислал | Куда легло |
|---|---|
| пересланный пост из канала или чата | папка `forward.folder` по шаблону `forward.template` |
| ссылку | папка `clipping.folder`, читаемый текст вытаскивает [trafilatura](https://github.com/adbar/trafilatura) |
| просто текст | строка в ежедневник под заголовок `daily.thought_heading` |
| фото, видео, голосовое, файл, альбом | папка из `attachments`, в заметку попадает `![[вставка]]` |
| `/<команда> Название` | заметка по шаблону в папку из `routes` |

Разметку Telegram бот переводит в markdown: жирное, курсив, зачёркнутое,
спойлер, `код`, блоки кода с языком, ссылки и цитаты. Вложения альбома
собираются в одну заметку, а не в пять.

Встроенные команды: `/new` (выбор шаблона кнопками), `/note`, `/task`, `/clip`,
`/today`, `/todo`, `/find`, `/read`, `/status`, `/cancel`, `/help`. Свои
команды из `routes` добавляются туда же, синонимы — в `aliases`.

## Быстрый старт

1. Получить токен у [@BotFather](https://t.me/BotFather) и узнать свой
   `chat_id` (например, написав `/start` боту и посмотрев в логи — он сам
   напишет id того, кто постучался).

2. Положить шаблоны в хранилище:

   ```bash
   cp templates/*.md /path/to/vault/Templates/
   ```

3. Настроить:

   ```bash
   cp .env.example .env            # BOT_TOKEN и ALLOWED_CHATS
   cp config.example.yml config.yml
   ```

   В `.env` дополнительно:

   ```ini
   VAULT_PATH=/path/to/vault
   TZ=Europe/Moscow
   UID=1000
   GID=1000
   ```

   `UID`/`GID` — чтобы созданные файлы принадлежали тебе, а не root.

4. Запустить:

   ```bash
   docker compose up -d --build
   docker compose logs -f
   ```

Без `ALLOWED_CHATS` бот **не стартует**: иначе он слушался бы любого, кто
нашёл его по имени.

## Настройка

`config.yml` — единственное место, где описано конкретное хранилище.

```yaml
vault_name: MyVault          # для ссылок obsidian://open
locale: en                   # en | ru — названия месяцев в форматах MMMM
date_format: "DD-MM-YYYY"    # как бот пишет даты в ответах и шаблонах

routes:
  service:
    template: service.md     # файл внутри templates_dir хранилища
    folder: Infra            # куда класть заметку
    ask: "Service name"      # что спросить, если команда пришла без аргумента
    aliases: [srv]           # дополнительные имена команды
```

Любой текст ответа переписывается без правки кода:

```yaml
messages:
  help_head: "Своя шапка помощи."
  saved_note: "Записал"
  confused: "Не понял, что с этим делать."
```

Отшив незнакомцев:

```yaml
strangers:
  cooldown: 600              # не отвечать чаще раза в 10 минут
  notify_owner: true         # доложить владельцу, кто постучался
  replies:
    - "Не туда."
    - "Мы не знакомы."
```

## Шаблоны

Бот подставляет в шаблоны свои токены `{{...}}`:

| Токен | Где доступен | Что в нём |
|---|---|---|
| `{{title}}` `{{content}}` `{{date}}` | везде | заголовок, тело, дата |
| `{{source}}` `{{channel}}` `{{link}}` `{{time}}` `{{attachments}}` `{{links}}` | пересланное | откуда пришло, вложения, ссылки из поста |
| `{{site}}` `{{author}}` `{{published}}` `{{excerpt}}` | статьи | метаданные страницы |

Заодно он **отрабатывает за Templater**, которого в докере нет:
`<% tp.file.title %>` и `<% tp.date.now("DD-MM-YYYY") %>` (разбор форматов
moment.js — `YYYY MM DD HH mm ss`, `MMMM`, `ww`, `gggg`, `[литерал]`).
Остальные вызовы `tp.*` вырезаются, чтобы в заметке не оставалось мусора.

## Проверка

```bash
python3 selftest.py
```

30 офлайн-проверок: форматы даты, разбор шаблонов, имена файлов, перевод
разметки (включая смещения при эмодзи), запись заметок и дописывание в
разделы ежедневника. Telegram и сеть не нужны.

## Чего он не делает

- не распознаёт голосовые — сохраняет файлом и вставляет в заметку;
- не правит и не удаляет существующие заметки, только создаёт и дописывает
  в разделы ежедневника;
- не умеет вебхуков, только long polling: наружу порты открывать не нужно.
